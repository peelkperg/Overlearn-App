## Key Technical Decisions Made (Permanent — Story 4.5)

- **Mechanism**: `onLongPress` + `delayLongPress={1000}` on the existing `Pressable` (not a new gesture handler). React Native calls `onPress` when finger lifts before threshold, `onLongPress` when threshold fires — AC #5 (tap-still-opens) satisfied at zero cost.
- **`submittedRef` pattern**: `useRef(false)` distinguishes blur-after-submit from blur-without-submit; on iOS `onSubmitEditing` fires before `onBlur`, so without this guard the revert branch would undo a successful save.
- **`onInlineRename` callback** in `SegmentListItem`: parent (`index.tsx`) owns the write via `runAction` — consistent with the existing `onRename`/`onDuplicate`/`onDelete` delegation pattern.
- **Direct `renameSegment` import** in `segment/[id].tsx`: the detail screen doesn't need `useSegments()`'s full list/sort plumbing; `useSegment(id)` already provides reactive re-rendering after the write.
- **TextInput styling**: matches the replaced `ThemedText` geometry exactly (fontSize/lineHeight/fontWeight, `padding: 0`, `borderWidth: 0`, `backgroundColor: 'transparent'`) — no layout shift on entering edit mode.
- **No new routes, no `stack-screens.ts` change, no new lib/ functions, no new component.**

## Key Technical Decisions Made (Permanent — Stories 4.1–4.4)

- **FR38 em dash**: `null` solidification renders "—", never "0%" — ux-design-specification.md §609.
- **FR38 rounding**: `formatSolidification` helper: exact 0→"0%", exact 100→"100%", strictly between clamps to [1,99] (`Math.min(99, Math.max(1, Math.round(pct)))`).
- **Sort defaults**: DEFAULT_SETTINGS uses `createdAt/asc`; DEFAULT_DIRECTION uses `createdAt/desc`. Two different defaults; both correct.
- **Name sort**: `localeCompare({ sensitivity: 'base', numeric: true })`.
- **subscribeToAnyHistory**: anchored regex `/^history\.[^.]+$/`.
