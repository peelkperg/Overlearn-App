# Overlearn

Mobile app applying the neuroscience of overlearning to musicians' technical practice: log failed attempts before a first correct repetition, then require a consecutive-correct streak (default 50% of that failure count, min 5, resets to zero on any miss) before a fix counts as solidified. Fully offline, local-storage only, no accounts/cloud/telemetry.
